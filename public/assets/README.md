# Visual Assets

Lightweight SVG / WebP assets for invitation framing.

- `frames/` — floral corner borders & dividers
- `flowers/` — watercolor botanicals
- `seals/` — wax seal marks

Prefer React components in `src/components/ui/ornaments/` when dynamic color/animation is needed.
Static files here are for `<img>` fallbacks and CDN-ready paths.
